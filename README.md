# mintbread
just art made by me and/or for me
## How to submit?
There are various ways you can submit an image.
### By Trollbox
When i am online on trollbox, use the following as a template:
"Hey mintbread can i add my art to your/my collection? [link to image]"
### By Github
Do the following:
1. Fork this repo.
2. Add your folder and/or images to submit.
3. Make a pull request with your forked repo.
4. Keep checking this repo, when your pull request is approved by me, you can party!
